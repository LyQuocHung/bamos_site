flake.nix — BamOS
description = "Hệ thống BamOS tối ưu cho Lập trình viên";

outputs = { self, nixpkgs, ... }: {
  nixosConfigurations.developer-machine = nixpkgs.lib.nixosSystem {
    system = "x86_64-linux";
    modules = [
      ./hardware-configuration.nix
      {
        # Môi trường Dev nhất quán
        environment.systemPackages = with pkgs; [
          git vscode docker neovim
        ];
        
        # Sẵn sàng Out-of-the-box
        services.xserver.videoDrivers = [ "nvidia" ];
      }
    ];
  };
};

Kiến trúc Tương lai

4 trụ cột công nghệ làm nên sự khác biệt của BamOS so với các hệ điều hành truyền thống.

Tuyệt đối Ổn định

Nhờ cơ chế quản lý gói của Nix, cập nhật không bao giờ làm hỏng hệ thống. Rollback về phiên bản cũ chỉ trong 1 giây.

Môi trường Nhất quán

Chia sẻ môi trường lập trình (tools, libs) cho cả team chỉ bằng một file cấu hình duy nhất (Declarative).

Out-of-the-box

Cài sẵn driver GPU (NVIDIA, AMD), Wayland và các công cụ cần thiết ngay từ lần khởi động đầu tiên.

Cộng đồng Việt

Hỗ trợ trực tiếp bằng tiếng Việt. Tài liệu phong phú, giải quyết lỗi nhanh chóng thông qua Discord & Matrix.

Developer Edition

Gaming / Studio Edition

Minimal Edition
